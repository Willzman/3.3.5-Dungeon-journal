# Dungeon Journal for 3.3.5a

| `/dj modeltest` | Report how your client loads boss models (for bug reports) |
A boss, loot and map journal for **every dungeon and raid in the Wrath of the Lich King 3.3.5a client**:
Classic, The Burning Crusade and Wrath of the Lich King content (80 instances, 614 boss and loot pages,
7,240 items). It is a 3.3.5a edition of DungeonJournal by Exehn, rebuilt for the 3.3.5a (build 12340,
Interface 30300) API.

## Installation

| `/dj modeltest` | Report how your client loads boss models (for bug reports) |

2. Copy the `DungeonJournal` folder into `World of Warcraft\Interface\AddOns\`, so this file exists:
   `Interface\AddOns\DungeonJournal\DungeonJournal.toc`
3. Start the game and type `/dj`.

## Features

| `/dj modeltest` | Report how your client loads boss models (for bug reports) |
- **Home page** with a card for each instance, filtered by expansion (Classic / The Burning Crusade /
  Wrath of the Lich King) and by Dungeons / Raids. The cards use the client's own Looking For Group art
  where the client has it.
- **Instance pages** list the bosses (with 3D portraits), the boss level and the loot.
  - **Difficulty buttons**: Normal / Heroic for 5-player dungeons, 10 / 25 player and 10 / 25 Heroic
    for Wrath raids.
  - **Faction-specific loot** (Trial of the Crusader, Koralon, etc.) shows your faction's items.
  - **Trash drops** and extra pages (patterns, chests, bonus loot).
- **Map tab** with the Atlas map of each instance (all wings and entrances) and its numbered map key.
- **Item tooltips** with Shift-compare; Shift-click to link in chat, Ctrl-click to try on.
  Items not cached yet show their name and quality from bundled data, then load from the server.
- **Search** across instances, bosses and loot (`Enter` in the search box, or `/dj search <text>`).
- **Favourites**: right-click any item to add or remove it; the Favourites window opens the boss
  each item came from.
- **Loot Filter**: only items your class can use, by armor type, hide recipes, or hide items that
  cannot be equipped.
- **Item source on tooltips**: any item tooltip in the game gets a "Dungeon Journal:" line naming the
  boss, instance and difficulty it drops from.
- Opens on the **instance you are in**, on the right difficulty.
- Minimap button, key binding (Key Bindings > Dungeon Journal), options under
  Interface > AddOns > Dungeon Journal, and a resizable window (drag the bottom-right corner).

## What is different from the original

| `/dj modeltest` | Report how your client loads boss models (for bug reports) |
- The original journal is built for the WoW Forever client and its own dungeons. This edition covers
  the instances of the 3.3.5a client instead and is written against the 3.3.5a API (no `C_` APIs,
  no Encounter Journal art).
- **Quests and quest chains are not included.** The original's quest pages, quest-giver map markers
  and dungeon routes were written by hand for the Forever dungeons. Loot, bosses and maps cover every
  3.3.5a instance; quests would be a separate, much larger data set.
- Instance and boss names are English. Item names follow your game client's language.

## Data sources

| `/dj modeltest` | Report how your client loads boss models (for bug reports) |
The loot tables are generated by the scripts in `tools/` (static parsing only; no third-party code is
executed):

| `/dj modeltest` | Report how your client loads boss models (for bug reports) |
- **AtlasLoot Enhanced v5.11.04**, the 3.3.5a release (TrinityCore `wow_335a_addons`, commit
  `4c551c5`): 10 and 25 player Naxxramas, Obsidian Sanctum, Eye of Eternity, Vault of Archavon and the
  Trial of the Crusader tribute chests, plus the bundled item names, qualities and slot text.
- **AtlasLootClassic** (commit `8e99341`): instance and boss structure, NPC IDs, creature display IDs,
  boss levels and all other loot tables. Wrath Classic-only content (Titan Rune difficulties, items the
  3.3.5a client does not have) is removed, and heroic 5-player emblems are set to Emblem of Triumph as
  on 3.3.5a.
- **Atlas 1.17.0** (3.3.5a): instance maps, map keys, level ranges and minimum levels.

| `/dj modeltest` | Report how your client loads boss models (for bug reports) |
All three are GPL (version 2 or later) and are credited here.
